Module 1

Cloud Productivity & Modern Workflows

1.1 Transitioning to Google Workspace (Docs & Sheets)

The Core Concept: While traditional desktop apps save files locally, modern remote teams run entirely on real-time cloud collaboration tools like Google Docs and Google Sheets accessible via web browsers from any device.

Why It's Needed First

Clients expect Virtual Assistants to collaborate in real-time. Cloud documents eliminate file loss, prevent version-control confusion (e.g., no more Document_v2_FINAL.docx), and allow multiple team members to edit simultaneously.

How to Use It

  • Google Docs: Use for meeting minutes, drafting client communications, and creating Standard Operating Procedures (SOPs). Use the top-right Share button to control editor/commenter access.
  • Google Sheets: Use for tracking tasks, budget monitoring, and contact lists. Learn foundational formulas (SUM, AVERAGE, COUNTIF) and use conditional formatting to highlight critical priorities.

1.2 Workspace Management with Notion

The Core Concept: Notion is an all-in-one workspace that acts as a digital wiki, project dashboard, and document hub combined into a single platform.

Why It's Needed First

VAs are hired to bring order to operational clutter. Notion enables you to organize client links, resources, guidelines, and project trackers into one clean, searchable system.

How to Use It

  1. Create a new page and set up a Kanban Board layout with three columns: To Do, In Progress, and Completed.
  2. Build an SOP Wiki: Document client tasks step-by-step using clear headings, toggle lists, and embedded screenshots.

Guided Student Exercise

Task: Create a Google Doc titled SOP: Weekly Email Cleanup. Outline a 5-step checklist for checking, labeling, and archiving client emails. Share the link with edit access.

Module 2

Executive Support & Inbox Mastery

2.1 Automated Scheduling & Time-Zone Management

The Core Concept: Managing executive schedules using Google Calendar paired with self-service booking links like Calendly or SavvyCal.

Why It's Needed First

Negotiating meeting times back-and-forth via email wastes valuable hours. Automated scheduling lets clients and contacts book slots instantly based on real-time availability.

How to Use It

  • Google Calendar: Enable secondary time zones (e.g., EST, GMT, WAT) in calendar settings to prevent scheduling errors when working with international clients.
  • Calendly: Link the executive’s Google Calendar, configure meeting duration rules (e.g., 30-min discovery call), add 15-minute buffer periods between sessions, and share the link.

2.2 Inbox Zero & Meeting Notes

The Core Concept: Organizing email to achieve "Inbox Zero" and utilizing AI transcription software (like Otter.ai or Fathom) within virtual meeting platforms.

Why It's Needed First

Executives are overwhelmed by hundreds of unread emails and hours of weekly calls. A VA who filters priorities and provides concise meeting summaries creates instant leverage.

How to Use It

  • Inbox Zero Strategy: Create Gmail Labels (e.g., @Action Required, @Waiting Response, @Archive) and set up automated filters for routine emails.
  • Meeting Summarization: Connect an AI assistant to Google Meet calls to generate meeting transcripts, extract action points, and draft follow-up notes for attendees.

Guided Student Exercise

Task: Create a mock Google Calendar event for an executive traveling between New York (EST) and London (GMT). Include a Google Meet link, add a 15-minute buffer time, and attach a travel brief doc.

Module 3

Applied AI Workflows & Prompting

3.1 Leveraging AI Assistants (ChatGPT & Gemini)

The Core Concept: Using Large Language Models to process commands (prompts), draft text, summarize documents, and transform data instantly.

Why It's Needed First

AI gives a single VA the speed of an entire operational team. Instead of drafting every letter or spreadsheet manually, you can generate structured baseline drafts in seconds.

How to Use It

Apply the C-R-E-A-T-E Prompting Framework for accurate results:

  • Context: Share the background ("I am a VA for a growing consulting agency...").
  • Role: Give AI a persona ("Act as an expert executive assistant...").
  • Explicit Instruction: State the exact output needed ("Draft a polite follow-up email...").
  • Attributes: Define style and length constraints ("Keep it under 150 words, warm yet firm...").
  • Examples: Provide a reference sample if available.

3.2 Core AI Applications for Virtual Assistants

Long-Doc Summaries

Paste long articles or reports and prompt: "Summarize this document into 5 key insights and 3 action items for my CEO."

Data Structuring

Paste unstructured text lists into AI and prompt: "Organize this raw text into a clean table with columns: Name, Email, and Status."

Professional Communication

Prompt AI to draft diplomatic replies for delicate situations (e.g., rescheduling a delayed deliverable politely).

Guided Student Exercise

Task: Copy a long news article or blog post. Write a structured prompt using the C-R-E-A-T-E framework in ChatGPT or Gemini to produce a 3-bullet executive summary and an action checklist.

Module 4

Communication & Password Security

4.1 Async Communication (Slack & Loom)

The Core Concept: Utilizing team chat apps alongside short screen-recording videos to share updates without needing live meetings.

Why It's Needed First

Remote teams operate across different schedules and locations. Communicating clearly through text and short video explanations keeps projects moving asynchronously.

How to Use It

  • Slack / Teams: Use threaded replies to keep channel conversations clean; update your status to reflect availability (e.g., Focused Work Mode).
  • Loom: Record 2-minute video walkthroughs showing your screen to explain finished work, report bugs, or present weekly updates.

4.2 Password Hygiene (1Password / Bitwarden)

The Core Concept: Storing and sharing confidential login credentials securely through encrypted password vaults.

Why It's Needed First

Professional clients will never text passwords or send them in plain emails. Understanding secure credential sharing is vital for maintaining client trust.

How to Use It

  • Never accept plain text passwords via chat or email attachments.
  • Ask clients to share credentials via 1Password or Bitwarden shared access links.
Module 5

Visual Content & Social Media Management

5.1 Visual Asset Design with Canva

The Core Concept: Using drag-and-drop design software to produce marketing collateral, banners, and presentation slides quickly.

Why It's Needed First

Clients often delegate light visual tasks—such as updating social banners, making event flyers, or polishing slide decks—to their virtual assistant.

How to Use It

  • Start with standard templates tailored for specific platforms (e.g., LinkedIn posts, presentation decks).
  • Use background removers, brand kits (consistent fonts/colors), and high-resolution export formats.

5.2 Basic Social Media Scheduling

The Core Concept: Planning and queuing social content ahead of time using scheduling tools like Buffer, Later, or Meta Business Suite.

Why It's Needed First

Consistent content posting drives client visibility. Scheduling tools let a VA prepare a full week of posts in one dedicated session.

Guided Student Exercise

Task: Use ChatGPT/Gemini to write 3 professional LinkedIn post captions promoting a client's workshop. Design a graphic in Canva for one post, and organize everything into a Google Sheets calendar template.
